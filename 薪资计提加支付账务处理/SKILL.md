# 薪资计提加支付账务处理

## 描述

本技能用于处理财务系统中薪资计提和实际支付的账务处理工作。根据薪酬管理模块的员工工资数据，自动生成计提凭证和支付凭证的会计分录，并在生成凭证前对会计科目和辅助核算进行完整性校验。

## 使用场景

- 财务人员月末/月初进行工资计提和发放的账务处理
- 需要自动生成薪资相关的会计凭证
- 需要对会计科目和辅助核算进行前置校验
- 涉及销售费用、管理费用、研发费用三类费用的分摊

## 触发条件

当用户提到以下内容时自动触发本技能：
- 薪资计提
- 工资计提
- 薪资支付
- 工资发放
- 计提工资凭证
- 发放工资凭证
- 薪酬账务处理
- 工资做账

## 指令

### 第一步：获取输入数据

1. 确认用户提供的薪酬数据来源（薪酬管理模块导出的表格/手动输入的员工列表）
2. 确认工资所属的公司名称和年月（用于生成凭证摘要）
3. 解析员工工资数据，确保每条记录包含：姓名、部门、费用类型、税前工资、个人社保、个人公积金、个税、实发工资

如果数据不完整，向用户询问缺失的信息。

### 第二步：校验会计科目和辅助核算

生成凭证前，必须按以下顺序依次校验，**任一环节不通过则停止并提示用户去维护**：

#### 2.1 校验会计科目是否存在

检查以下科目是否存在于会计科目模块中：

**借方费用科目（按员工费用类型逐一检查）：**
- 66010101 销售费用_职工薪酬_工资
- 66020101 管理费用_职工薪酬_工资
- 5301010101 研发支出_费用化支出_职工薪酬_工资

**贷方/支付科目：**
- 221101 应付职工薪酬_工资
- 122101 其他应收款_社会/医疗保险费
- 122102 其他应收款_住房公积金
- 222101 应交税费_应交个人所得税
- 100201 银行存款

> **注意**：如果用户使用的科目编码与上述不同，请以用户系统中的实际科目编码为准，让用户提供对应关系。

#### 2.2 校验科目是否开通辅助核算

对以下需要辅助核算的科目，检查是否开通了对应的辅助核算类型：

| 科目 | 需开通的辅助核算类型 |
|-----|-------------------|
| 66010101 销售费用_职工薪酬_工资 | 部门、职员 |
| 66020101 管理费用_职工薪酬_工资 | 部门、职员 |
| 5301010101 研发支出_费用化支出_职工薪酬_工资 | 部门、职员 |

#### 2.3 校验辅助核算明细是否存在

根据员工数据，逐一检查以下辅助核算明细是否存在：

- **部门辅助核算**：员工所属部门是否在部门辅助核算档案中存在
- **职员辅助核算**：员工姓名是否在职员辅助核算档案中存在

#### 校验结果处理

- 所有校验通过：继续第三步
- 任一校验不通过：列出所有缺失项，提示用户先去维护，维护完成后再重新执行

### 第三步：生成计提凭证

#### 摘要格式
`支付{公司名称}工资{年}-{月}`

#### 借方分录（按员工逐行生成）

每个员工一行借方分录：

- 科目：根据费用类型映射对应的费用科目
- 金额：该员工的税前工资
- 辅助核算：部门（该员工所属部门）、职员（该员工姓名）
- 摘要：统一使用上述摘要格式

#### 贷方分录（合计一行）

- 科目：应付职工薪酬_工资
- 金额：所有员工税前工资的合计值
- 辅助核算：无
- 摘要：统一使用上述摘要格式

### 第四步：生成实际支付凭证

#### 摘要格式
`支付{公司名称}工资{年}-{月}`

#### 借方分录（一行）

- 科目：应付职工薪酬_工资
- 金额：所有员工税前工资的合计值
- 辅助核算：无
- 摘要：统一使用上述摘要格式

#### 贷方分录（四行）

1. **个人社保**
   - 科目：其他应收款_社会/医疗保险费
   - 金额：所有员工个人社保的合计值
   - 辅助核算：无

2. **个人公积金**
   - 科目：其他应收款_住房公积金
   - 金额：所有员工个人公积金的合计值
   - 辅助核算：无

3. **个税**
   - 科目：应交税费_应交个人所得税
   - 金额：所有员工个税的合计值
   - 辅助核算：无

4. **实发工资**
   - 科目：银行存款
   - 金额：所有员工实发工资的合计值
   - 辅助核算：无

### 第五步：输出结果

将两张凭证（计提凭证、支付凭证）以清晰的格式输出给用户，包含：

1. 凭证类型（计提/支付）
2. 凭证摘要
3. 分录明细（借方/贷方、科目编码、科目名称、金额、辅助核算）
4. 合计金额（借方合计 = 贷方合计）

## 计算规则

### 合计计算

- 税前工资合计 = Σ(各员工税前工资)
- 个人社保合计 = Σ(各员工个人社保)
- 个人公积金合计 = Σ(各员工个人公积金)
- 个税合计 = Σ(各员工个税)
- 实发工资合计 = Σ(各员工实发工资)

### 借贷平衡验证

- 计提凭证：借方合计（费用合计）= 贷方合计（应付职工薪酬）
- 支付凭证：借方合计（应付职工薪酬）= 贷方合计（个人社保 + 个人公积金 + 个税 + 银行存款）

## 注意事项

1. **校验顺序不可跳过**：科目存在性 → 辅助核算开通 → 辅助核算明细存在，必须按此顺序校验
2. **费用类型映射**：根据员工的"费用类型"字段自动匹配对应的费用科目
3. **辅助核算**：仅费用类科目需要部门和职员辅助核算，其他科目不需要
4. **数据准确性**：确保金额计算正确，借贷平衡
5. **用户系统差异**：如果用户的科目编码、科目名称与本技能预设不同，以用户实际系统为准，请用户提供对应映射关系
6. **脚本使用**：可调用 `scripts/generate_voucher.py` 脚本自动生成凭证，传入薪酬数据JSON和公司信息即可
